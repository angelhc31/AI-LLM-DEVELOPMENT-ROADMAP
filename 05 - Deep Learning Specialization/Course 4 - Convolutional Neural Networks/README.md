# 🧠 Convolutional Neural Networks - DeepLearning.AI (Andrew Ng) - Coursera

[The course](https://www.coursera.org/learn/convolutional-neural-networks?specialization=deep-learning)

Here you will find exercises, notes, and course material completed as part of the **Convolutional Neural Networks** course, taught by Andrew Ng on Coursera.

Throughout the course, I explored topics including:

* Foundations of convolutional neural networks (CNNs)
* Convolution and pooling layers for image processing
* Deep convolutional architectures and classic CNN case studies
* Residual networks (ResNets), Inception, MobileNet, EfficientNet
* Transfer learning and data augmentation for computer vision
* Object localization, landmark detection, and object detection
* Sliding windows, bounding boxes, IoU, non-max suppression, anchor boxes
* YOLO-based detection and semantic segmentation with U-Net
* Face recognition with one-shot learning and Siamese/triplet networks
* Neural style transfer and applications of CNNs beyond images
