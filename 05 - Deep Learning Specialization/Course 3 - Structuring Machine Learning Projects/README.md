# 🧠 Structuring Machine Learning Projects – DeepLearning.AI (Andrew Ng) – Coursera

[The course](https://www.coursera.org/learn/machine-learning-projects?specialization=deep-learning)

Here you will find exercises, notes, and course material completed as part of the **Structuring Machine Learning Projects** course, taught by Andrew Ng on Coursera.

Throughout the course, I explored topics including:

* Best practices for building machine learning systems that work in production
* Error analysis for iterative improvement
* Preventing data leakage and establishing proper data pipeline hygiene
* Orthogonalization and how to address ML problems systematically
* Techniques for handling mismatched training/test distributions
* Strategies for human-level performance comparison and setting realistic baselines
* Guidelines for when to collect more data, tune algorithms, or adjust labels
* Avoiding overly complex ML troubleshooting with clear diagnostic workflows
* End-to-end ML project structuring for scalable experimentation
