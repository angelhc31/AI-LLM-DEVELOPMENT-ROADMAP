# 🧠 Improving Deep Neural Networks: Hyperparameter Tuning, Regularization and Optimization - DeepLearning.AI (Andrew Ng) - Coursera

[The course](https://www.coursera.org/learn/deep-neural-network?specialization=deep-learning)

Here you will find exercises, notes, and course material completed as part of the **Improving Deep Neural Networks: Hyperparameter Tuning, Regularization and Optimization** course, taught by Andrew Ng on Coursera.

Throughout the course, I explored topics including:

* Bias/variance analysis and data splitting (Train/Dev/Test)
* Regularization methods: L2 regularization and dropout
* Weight initialization strategies to address vanishing/exploding gradients
* Gradient checking and numerical approximation of gradients
* Mini-batch gradient descent, momentum, RMSProp, and Adam optimization
* Learning rate decay and exponentially weighted averages
* Batch normalization and activation normalization in deep networks
* Hyperparameter tuning best practices and search strategies
* TensorFlow basics for deep learning implementation and experimentation
