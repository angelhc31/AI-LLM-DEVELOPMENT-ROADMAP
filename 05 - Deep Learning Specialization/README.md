# 🧠 Deep Learning Specialization - DeepLearning.AI (Andrew Ng) - Coursera

[The Specialization](https://www.coursera.org/specializations/deep-learning)

This specialization is an online program created by DeepLearning.AI, designed to teach the foundations and practical applications of deep learning. It is beginner-friendly but progressively covers advanced topics, allowing learners to build real-world AI models. The specialization consists of the following courses:

1. **Neural Networks and Deep Learning**
   Introduces the basics of neural networks, how they work, and how to implement them using Python and TensorFlow. Topics include activation functions, forward and backward propagation, and building deep learning models. [The course](https://www.coursera.org/learn/neural-networks-deep-learning?specialization=deep-learning)

2. **Improving Deep Neural Networks: Hyperparameter Tuning, Regularization and Optimization**
   Focuses on improving deep learning models using techniques such as regularization, dropout, batch normalization, and optimization algorithms. Also covers hyperparameter tuning and practical tips for training deep neural networks. [The course](https://www.coursera.org/learn/deep-neural-network?specialization=deep-learning)

3. **Structuring Machine Learning Projects**
   Teaches best practices for structuring and managing machine learning and deep learning projects, including error analysis, setting up development and production pipelines, and diagnosing bias vs. variance problems. [The course](https://www.coursera.org/learn/machine-learning-projects?specialization=deep-learning)

4. **Convolutional Neural Networks (CNNs)**
   Covers CNNs for image recognition, classification, and detection tasks. Includes practical applications like self-driving cars, medical imaging, and implementing architectures like ResNet and Inception. [The course](https://www.coursera.org/learn/convolutional-neural-networks?specialization=deep-learning)

5. **Sequence Models**
   Explores sequence data modeling using RNNs, LSTMs, GRUs, and attention mechanisms. Applications include natural language processing, speech recognition, and time series prediction. [The course](https://www.coursera.org/learn/nlp-sequence-models?specialization=deep-learning)
