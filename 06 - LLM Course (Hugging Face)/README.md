# 🤗 Hugging Face LLM Course

[The course](https://huggingface.co/learn/llm-course/chapter1/1)

Here you will find exercises, notes, and course material completed as part of the **Hugging Face LLM Course**, focused on large language models (LLMs), NLP, and the Hugging Face ecosystem (Transformers, Datasets, Tokenizers, Accelerate, and the Hub).  The course is completely free and combines traditional NLP concepts with modern LLM techniques.

Throughout the course, I explored topics including:

* Foundations of NLP and LLMs, and how they relate to each other  
* Using 🤗 Transformers and the `pipeline()` function for tasks like text classification and text generation  
* Loading, fine-tuning, and sharing models and datasets on the Hugging Face Hub  
* Working with 🤗 Datasets and 🤗 Tokenizers to preprocess and prepare data for training  
* Core Transformer concepts: encoder, decoder, encoder–decoder architectures, self-attention, and multi-head attention  
* Implementing and experimenting with classic NLP tasks and modern LLM workflows  
* Building and sharing demos for models (e.g., with Gradio) and deploying them from the Hub  
* Advanced topics such as fine-tuning LLMs, dataset curation, and building reasoning-capable models
